# My Commons

Common utility classes and functions used in my Dart and Flutter projects.

## Requirements

- Flutter 3.50.1 or later with Dart 3.14.0 or later (Dart 3.x).
- If you use `buildCheckboxes` or `buildDropdownList`, import
  `package:material_ui/material_ui.dart` in the host app too. Use its
  `MaterialApp` and `Theme` so these widgets pick up the app's Material theme.
